HAC 인원 관리 사용 방법

  1. 관리 화면을 열면 MockAPI에서 목록을 조회하여 화면에 표시합니다.
  2. 이름, 학번, 별명, 출석 횟수, 전화번호를 입력 및 등록.
  3. 수정 버튼을 누르면 기존 정보가 수정 란에 표시됩니다. 수정 후 등록 또는 취소를 선택
  4. 삭제 버튼을 누른 후 확인하면 서버에서도 삭제됩니다.
  5. 이름 또는 별명을 전부 입력하여 검색할 수 있습니다.

이름은 2글자 이상, 학번은 16~26으로 시작하는 8자리 숫자를 입력해야 합니다. 출석 횟수는 숫자만 입력

요청에 실패하면 알림을 확인합니다.
